# HTML5 页面布局作业

> 万物互联、极致体验 —— 前端校内作业

## 项目简介

本项目是一份前端页面布局作业，要求根据给定的设计截图完成 HTML 页面布局，使用附件中提供的字体与图标素材，并将源码推送到 GitHub / Gitee。

页面包含三个区域：

1. **标题区**："万物互联、极致体验"，使用书法字体展示
2. **HTML5 介绍区**：左右两栏，每栏包含 HTML5/CSS3 logo 及介绍文字
3. **平台支持区**：展示四个平台开发方向（原生移动 APP、微信公共平台、网站、桌面应用），配以对应图标

## 技术实现

- 纯 HTML + CSS，无框架依赖
- 字体：使用附件 `素材/fonts/书法.ttf`（标题）、FontAwesome 4.5.0（图标库备选）
- 图标：使用附件 `素材/images/` 下的 PNG 图片（与设计稿一致）
- 布局：Flexbox 两栏 / 四栏等分布局

## 运行方式

直接在浏览器中打开 `index.html` 即可。

或启动本地静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 工作流总结

本次作业从需求到交付的完整工作流如下：

```
需求理解 → 素材盘点 → 页面开发 → 预览验证 → 环境准备 → 版本控制 → 推送交付
```

### 各阶段说明

| 阶段 | 动作 | 产出 |
|------|------|------|
| **1. 需求理解** | 分析作业截图与要求，明确页面结构（标题区 / HTML5 介绍区 / 平台支持区）和交付物（HTML 文件 + Git 仓库链接） | 页面结构清单 |
| **2. 素材盘点** | 遍历 `素材/` 目录，查看 6 张 PNG 图片、字体文件和 FontAwesome CSS，确认每个素材的用途 | 素材-用途映射表 |
| **3. 页面开发** | 编写 `index.html`：书法字体标题 + Flexbox 两栏/四栏布局 + 文字两端对齐 | `index.html` |
| **4. 预览验证** | 启动 `python -m http.server`，浏览器截图逐区核对标题字体、logo、文字、平台图标是否与设计稿一致 | 验证通过的页面 |
| **5. 环境准备** | 检测到系统无 Git，通过 `winget` 安装 Git 2.55 | 可用的 Git 环境 |
| **6. 版本控制** | `git init` → 配置用户 → `git add -A` → `git commit`（16 个文件） | 本地提交 `88dcc5f` |
| **7. 推送交付** | 用 PAT 推送到 GitHub `html5-homework` 仓库（经历权限不足 → 指导用户更新权限 → 成功），`git ls-remote` 确认同步，清理 URL 中的令牌 | 远端仓库 + 提交哈希一致 |

### 关键决策点

- **图标实现方式**：附件同时提供了 PNG 图片和 FontAwesome 图标库。由于 PNG 图片与设计稿完全一致，选择直接使用图片，而非 FontAwesome 字符图标。
- **Git 安装方式**：沙箱内 winget 被拦截，改用 `dangerouslyDisableSandbox` 绕过完成安装。
- **令牌权限处理**：细粒度 PAT 首次缺 `Administration` 和 `Contents` 权限，分别通过"用户手动建仓"和"用户更新令牌权限"解决，未强推或破坏仓库。
